2. Endpoint 1: POST /api/v1/detect (Part A: Detection) POST /detect

Executes fine-tuned RT-DETR-L object detection on uploaded construction site images. Filters predictions at the unified 0.45 confidence cutoff, computes Laplacian focus blur, and outputs exact bounding box coordinates with per-class breakdowns (person, hat, vest).

Request Format: cURL (Multipart) Bash
curl -X POST "http://localhost:8000/api/v1/detect" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@site_worker.jpg;type=image/jpeg"
Request Format: Python Requests Python 3.10+
import requests
url = "http://localhost:8000/api/v1/detect"
with open("site_worker.jpg", "rb") as f:
    files = {"file": ("site.jpg", f, "image/jpeg")}
    res = requests.post(url, files=files).json()

3. Endpoint 2: POST /api/v1/reason (Part B: Minimal Reasoning Layer) POST /reason

Hand-written reasoning pipeline (strictly zero agentic frameworks): [1] Intent Router classifies token necessity → [2] RT-DETR executes object detection if visual → [3] Confidence Guardrail validates sharpness & confidence cutoff → [4] Native Groq SDK (llama-3.3-70b-versatile) generates plain English compliance audit.

Scenario A: Visual Safety Question (Compliant Detection & Audit Response) 200 OK
# cURL Request:
curl -X POST "http://localhost:8000/api/v1/reason" -F "file=@site.jpg" -F "question=Is the worker compliant with helmet and vest safety rules?"
# JSON Response:
{
  "status": "success",
  "question": "Is the worker compliant with helmet and vest safety rules?",
  "intent_routing": { "needs_detection": true, "intent_category": "visual_inspection", "confidence": 0.98, "matched_pattern": "\\bhelmet\\b|\\bvest\\b" },
  "detector_called": true,
  "guardrail_result": { "is_sufficient": true, "laplacian_variance": 192.4, "message": "Sufficient information: Sharpness and confidence exceed thresholds." },
