5. Architectural Pillars & Hard Constraint Compliance Audit Screening Verified

1. Zero Agentic Frameworks

Strictly compliant. 0 lines of LangChain, CrewAI, or AutoGen. Pure deterministic regex intent router + native Groq SDK chat completions.

2. Unified 0.45 Threshold

A single threshold of 0.45 governs both raw bounding-box NMS filtering and downstream Guardrail validation, eliminating threshold mismatch bugs.

3. In-Memory Processing

Uploaded images flow strictly via memory buffers (BytesIO → PIL → Tensor) and are discarded post-inference. Zero user images are stored to disk.

4. ZeroGPU + CPU Resiliency

Primary inference leverages NVIDIA A10G ZeroGPU. If daily quota is exhausted, the system seamlessly routes to unlimited CPU fallback with zero downtime.
